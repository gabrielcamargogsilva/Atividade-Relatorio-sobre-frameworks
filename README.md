# Resumo da Aula 01 — Frameworks Front End

Este repositório contém o resumo da Aula 01 e o relatório técnico sobre frameworks front-end.

## Aula 01

A primeira aula apresentou os fundamentos do desenvolvimento front-end e a organização de um projeto web desde a implementação até sua publicação. Também foram introduzidos o uso do Git e do GitHub para versionamento e colaboração, além do deploy de aplicações na Vercel.

### Atividade 01 — Jogo da Memória

#### Descrição

Desenvolvimento de uma aplicação web interativa utilizando as principais linguagens fundamentais da Web. O projeto consiste em um jogo da memória no qual o usuário deve encontrar os pares de cartas iguais.

#### Objetivos

- Praticar a estruturação de páginas com HTML5.
- Aplicar estilos e layout responsivo com CSS3.
- Utilizar JavaScript para criar interatividade e controlar a lógica do jogo.
- Organizar o código em um repositório GitHub.
- Realizar o deploy da aplicação na Vercel.

#### Tecnologias

- **HTML5:** estrutura e organização dos elementos da página.
- **CSS3:** aparência visual, posicionamento e responsividade.
- **JavaScript:** eventos, embaralhamento das cartas, controle das jogadas e identificação dos pares.
- **Git e GitHub:** versionamento e armazenamento do código-fonte.
- **Vercel:** publicação da aplicação na Web.

#### Links da atividade

- [Repositório do jogo da memória](https://github.com/gabrielcamargogsilva/jogo-da-memoria.git)
- [Deploy na Vercel](https://jogo-da-memoria-weld-pi.vercel.app/)

### Aprendizados da Aula 01

Durante a atividade, foi possível compreender que o desenvolvimento front-end combina três responsabilidades principais:

1. **Estrutura:** o HTML define o conteúdo e a semântica da aplicação.
2. **Apresentação:** o CSS define cores, fontes, espaçamentos, posicionamento e adaptação a diferentes telas.
3. **Comportamento:** o JavaScript responde às ações do usuário e altera o conteúdo da página dinamicamente.

O projeto também reforçou a importância de separar responsabilidades, testar o comportamento da aplicação durante o desenvolvimento e utilizar o controle de versão para acompanhar as alterações realizadas.
